🚀 Push to GitHub & Firebase Hosting

A GitHub Actions workflow is pre-configured in .github/workflows/firebase-hosting-merge.yml. Whenever you push to GitHub, it will automatically build and deploy this website to Firebase Hosting.

1. In GitHub repo settings -> Secrets and variables -> Actions, add Secret:

FIREBASE_SERVICE_ACCOUNT_LIFECYCLE_ORGANICS = <Your downloaded JSON key>

2. Push your code to GitHub:

git add . && git commit -m "Update portal" && git push
